# Print Kiosk

Киоск самообслуживания для печати, копирования и сканирования. Полноэкранный терминал, админ-панель, учёт бумаги, почта и мессенджер MAX.

Целевая машина — Windows у МФУ. Сборку можно делать на macOS/Linux.

## Возможности

- **Печать с USB** — обзор флешки, Office → PDF (LibreOffice), превью, ч/б или цвет, двусторонняя печать
- **Печать с Email** — письмо с вложением на ящик киоска (IMAP)
- **Печать с MAX** — файл боту, подтверждение на киоске
- **Многостраничное сканирование** — до 30 листов в одном PDF, крупный предпросмотр, миниатюры, удаление и бесплатное пересканирование выбранной страницы
- **Доплата за сканы** — первый лист оплачивается перед началом, дополнительные оставшиеся страницы оплачиваются перед выдачей общего PDF
- **Получение скана** — объединённый PDF можно сохранить на USB или отправить через Email/MAX
- **Копирование** — скан со стекла и печать на ту же очередь, что и обычная печать
- **Предпросмотр печати** — постраничный PDF, диапазон страниц, число копий и общая ориентация документа
- **Kiosk UI** — интерфейс 1080×1920, крупные touch targets, этапы операции, единые состояния загрузки/успеха/ошибки
- **Админка** — цены, бумага, оборудование, Email, MAX, оплата, статистика, журнал операций и системные настройки
- **История операций** — печать/копирование/сканирование, результат, страницы, листы, сумма и текст ошибки; хранение 30 дней
- **PDF-отчёт** — просмотр, печать диапазона страниц или отправка отчёта на USB, Email и MAX
- **Пуши в MAX** — старт/стоп, ошибки, бумага ниже порога, ежедневная статистика в 22:00

Карточки Email и MAX на терминале скрыты, если сервис выключен или не настроен.

## Требования

- Go 1.25+
- SQLite (`modernc.org/sqlite`, CGO не нужен)
- LibreOffice — для Word/Excel/PowerPoint (на Windows ставится сам при первом запуске)
- Принтер с драйвером Windows; желательно [SumatraPDF](https://www.sumatrapdfreader.org/) рядом с `print-kiosk.exe`
- Сканер того же МФУ должен быть виден Windows как **WIA**. Опционально [NAPS2](https://www.naps2.com/) (`NAPS2.Console.exe`)
- Для почты — ящик Yandex / Mail.ru / Gmail и **пароль приложения**
- Для MAX — верифицированный бизнес-профиль и бот на [business.max.ru](https://business.max.ru)

## Быстрый старт (разработка)

```bash
cp configs/config.example.yaml configs/config.yaml
# поправьте admin.password
go run . -config configs/config.yaml
```

- Киоск: http://127.0.0.1:8080/
- Админка: http://127.0.0.1:8080/admin/
- Проверка: http://127.0.0.1:8080/healthz

На Windows стартовая страница открывается в Edge/Chrome **на весь экран без рамок** (`--kiosk`). Пользовательские свайпы и системная навигация браузера блокируются kiosk-host слоем. Специалист может свернуть окно из кабинета. Обычная вкладка: `server.open_browser: false` в `config.yaml`.

Без железа можно включить тестовые режимы принтера и оплаты в кабинете специалиста. Настройка YAML также принудительно включает безопасный режим устройств:

```yaml
printer:
  dry_run: true
```

В тестовом режиме печать не уходит на принтер, скан/копия не обращаются к устройству, а оплата и выполнение имитируются таймерами.

## Сборка под Windows

Локально с Mac/Linux:

```bash
./scripts/build-windows.sh
```

Или артефакт GitHub Actions: **Actions → Build Windows → Artifacts → `print-kiosk-windows-amd64`**.

На ПК:

1. Распаковать zip в `C:\print-kiosk\`
2. Запустить `start.bat` (создаст `config.yaml` из примера)
3. Указать `admin.password` и `printer.name` (очередь из «Параметры → Принтеры»)
4. Снова запустить `start.bat`
5. Для автозапуска выполнить `deploy\windows\install-autostart.bat`

Подробности: `deploy/windows/README.txt`.

## Где что хранится

### YAML (`configs/config.yaml`)

Меняется файлом, применяется при **запуске** приложения.

| Поле | Смысл |
|---|---|
| `server.addr` | Адрес HTTP, по умолчанию `:8080` |
| `server.open_browser` | Открыть киоск-окно (по умолчанию true на Windows) |
| `admin.username` / `admin.password` | Вход в админку. Пароль через API не отдаётся |
| `database.path` | SQLite, по умолчанию `data/kiosk.db` |
| `logging.path` / `logging.level` | Журнал, по умолчанию `logs/kiosk.log` |
| `printer.name` | Очередь Windows; пусто = принтер по умолчанию |
| `printer.sumatra` | Путь к `SumatraPDF.exe` |
| `printer.dry_run` | Не слать на принтер и не дергать сканер |
| `paths.libreoffice` | `soffice` или полный путь |
| `payment.driver_url` | Зарезервировано; реальный терминал пока не подключён |

### SQLite (админка)

Цены, бумага, почта, MAX и флаги услуг. Правки применяются **сразу**, без перезапуска.

| Ключ | Смысл |
|---|---|
| `price_bw` / `price_color` | Печать, ₽ за лист |
| `price_copy` / `price_copy_color` | Чёрно-белая / цветная копия, ₽ за лист |
| `price_scan` | Сканирование, ₽ за документ |
| `paper_remaining` | Остаток листов. Кнопка «Бумага загружена» пишет 500 |
| `paper_alert_threshold` | Порог пуша в MAX |
| `email_address` / `email_login` / `email_password` | Ящик киоска |
| `email_poll_interval_sec` | Интервал IMAP, минимум 5 с |
| `email_max_file_size_mb` | Лимит вложения |
| `source_email_enabled` | Показывать Email на терминале (нужны ещё адрес и пароль) |
| `max_enabled` / `max_bot_token` | Галочка и токен показывают MAX в печати и сканировании |
| `max_admin_id` | User ID для уведомлений о бумаге. Без него киоск всё равно показывает MAX |
| `service_print_enabled` / `service_copy_enabled` / `service_scan_enabled` | Карточки на главной |
| `source_usb_enabled` | USB для печати и сохранения сканов |
| `test_device_mode` | Имитировать печать, копирование и сканирование без оборудования |
| `test_payment_mode` | Имитировать оплату без терминала |
| `session_timeout_sec` | Бездействие на терминале, затем главная и очистка файлов. `0` — не возвращать. Меньше 15 с округляется до 15 |
| `support_text` | Текст «Связаться с менеджером» |
| `kiosk_name` / `kiosk_id` / `kiosk_location` | Подписи в обзоре админки |

IMAP/SMTP-хосты не хранятся: считаются по домену адреса.

## Админка

Разделы: Обзор, Выгрузить историю, Цены, Бумага, Оборудование, Email, MAX, Оплата и Система.

Показываются только рабочие настройки. Пароль приложения и токен MAX маскируются (`********`).

- **Обзор** — бумага `остаток / 500`, принтер (в т.ч. «Режим тестирования» при `dry_run`), Email/MAX, оплата
- **Оборудование** — очередь принтера, режим устройств, сканер, Sumatra и LibreOffice
- **Email** — «Проверить подключение»: реальный IMAP + SMTP auth
- **MAX** — «Проверить MAX» (API), автоматическое определение имени бота и отдельное тестовое сообщение
- **Оплата** — тестовый режим или обращение к настроенному драйверу терминала
- **История** — период от 1 до 30 дней, крупная таблица, PDF-превью, печать и выдача отчёта

Карточки настроек можно сворачивать. Нередактируемые значения помечены как состояние системы, а панель сохранения закреплена внизу экрана.

## Почта

Один ящик на приём (IMAP) и отправку сканов (SMTP).

Печать: клиент шлёт письмо с файлом → на киоске «Я отправил письмо» → подтверждение → печать. Предлагается последнее письмо; «Нет» удаляет только его и ищет дальше.

После печати/отправки локальные копии удаляются.

## MAX

1. Токен бота и **ID админа** (`user_id`)
2. Галочка **Активировать MAX**

Без галочки, токена или ID бот не обрабатывает сообщения и не шлёт пуши. Включение/выключение без перезапуска.

**Пуши админу:** запуск, выключение, ошибки, бумага ниже порога, отчёт в 22:00.

**Печать:** файл боту → подтвердить на киоске.

**Скан:** код на экране → написать боту → PDF в MAX.

API: `https://platform-api2.max.ru`.

## Печать, копия, скан

Печать PDF на Windows — SumatraPDF (тихо, без диалога) или ассоциация Windows. На Unix — `lp` / `lpr`.

**Скан (Windows):** NAPS2 Console, если установлен, иначе WIA. Результат — A4 PDF.

**Копия:** скан со стекла, затем та же печать, что у обычного задания (цвет и число копий с киоска).

Ошибка сканера/печати возвращает бумагу, если листы уже списаны.

## Оплата и бумага

В тестовом режиме оплата имитируется примерно за 5 секунд. При выключенном тестовом режиме приложение обращается к `payment.driver_url`. QR не подключён. Печать, копия и скан без успешной оплаты не запускаются.

Счётчик листов атомарный (`BEGIN IMMEDIATE`): списание до печати/копии, возврат при ошибке. «Бумага загружена» пишет 500 в тот же ключ SQLite.

## Сессия на терминале

`session_timeout_sec` из админки. После бездействия — возврат на главную и удаление временных файлов текущего задания (печать, скан, копия, сессии Email/MAX), чтобы следующий посетитель их не увидел.

Экраны ожидания письма/файла MAX этот таймер не используют (окно до 2 минут).

## Что ещё не подключено

- **Конкретная модель платёжного терминала** — требуется совместимый локальный драйвер по `payment.driver_url`
- **QR-оплата** — не подключена

Копирование и сканирование — не заглушки, если `dry_run: false` и устройство видно системе.

## Структура

```
main.go                 запуск, graceful shutdown
internal/kiosk/         публичный UI и API киоска
internal/kioskhost/     Windows kiosk-окно, блокировка навигации и сворачивание
internal/admin/         админка
internal/printjob/      подготовка и печать
internal/scanjob/       заказы скана
internal/copyjob/       заказы копии
internal/device/        WIA / NAPS2 / scanimage → PDF
internal/mailinbox/     IMAP
internal/mailout/       SMTP
internal/maxsvc/        бот MAX, пуши, сессии
internal/stats/         дневная статистика
internal/ophistory/     история операций и очистка записей старше 30 дней
internal/storage/       SQLite, настройки, бумага
internal/usb/           флешки
internal/libreoffice/   поиск/установка soffice
```

Данные: `data/` (БД, задания), `logs/`. После доставки скана PDF с диска удаляется.
