# Print Kiosk

Киоск самообслуживания для печати, копирования и сканирования документов. Веб-интерфейс на весь экран, админ-панель, учёт бумаги, оплата (заглушка терминала), почта и мессенджер MAX.

Целевая машина — Windows у принтера. Сборку можно делать на macOS/Linux.

## Возможности

- **Печать с USB** — обзор флешки, конвертация Office → PDF (LibreOffice), превью, ч/б или цвет, двусторонняя печать
- **Печать с Email** — письмо с вложением на ящик киоска (IMAP)
- **Печать с MAX** — файл боту в MAX, подтверждение на киоске
- **Сканирование** — PDF на USB, email или MAX
- **Копирование** — оплата и отправка на МФУ (заглушка устройства)
- **Админка** — цены, бумага, почта, MAX, таймаут сессии
- **Пуши в MAX** — старт/стоп, ошибки, бумага, ежедневная статистика в 22:00

## Требования

- Go 1.25+
- SQLite (через `modernc.org/sqlite`, CGO не нужен)
- LibreOffice — для Word/Excel/PowerPoint (на Windows ставится сам при первом запуске)
- Принтер с драйвером Windows; желательно [SumatraPDF](https://www.sumatrapdfreader.org/) рядом с `print-kiosk.exe` для тихой печати
- Для почты — ящик Yandex / Mail.ru / Gmail и **пароль приложения**
- Для MAX — верифицированный бизнес-профиль и бот на [business.max.ru](https://business.max.ru)

## Быстрый старт (разработка)

```bash
cp configs/config.example.yaml configs/config.yaml
# поправьте admin.password
go run . -config configs/config.yaml
```

- Киоск: http://127.0.0.1:8080/
- Админка: http://127.0.0.1:8080/admin/
- Проверка: http://127.0.0.1:8080/healthz

На Windows стартовая страница открывается в Edge/Chrome **на весь экран без рамок** (`--kiosk`). Выход: Alt+F4. Чтобы открывать обычную вкладку, в `config.yaml` поставьте `server.open_browser: false` и зайдите в браузер сами.

Для UI без принтера в `config.yaml`:

```yaml
printer:
  dry_run: true
```

## Сборка под Windows

Локально с Mac/Linux:

```bash
./scripts/build-windows.sh
```

Или артефакт GitHub Actions: **Actions → Build Windows → Artifacts → `print-kiosk-windows-amd64`**.

На ПК:

1. Распаковать zip в `C:\print-kiosk\`
2. Запустить `start.bat` (создаст `config.yaml` из примера)
3. Указать `admin.password` и `printer.name` (имя очереди из «Параметры → Принтеры»)
4. Снова запустить `start.bat`

Подробности: `deploy/windows/README.txt`.

## Конфиг (`configs/config.yaml`)

| Поле | Смысл |
|---|---|
| `server.addr` | Адрес HTTP, по умолчанию `:8080` |
| `admin.username` / `admin.password` | Вход в админку |
| `database.path` | SQLite, по умолчанию `data/kiosk.db` |
| `printer.name` | Очередь Windows; пусто = принтер по умолчанию |
| `printer.sumatra` | Путь к `SumatraPDF.exe` |
| `printer.dry_run` | Не слать задания на принтер |
| `paths.libreoffice` | `soffice` или полный путь |

Цены, бумага, почта и MAX хранятся в БД и правятся в админке, не в YAML.

## Почта

Один ящик на приём (IMAP) и отправку сканов (SMTP). В админке: адрес, логин, пароль приложения, интервал проверки.

Печать: клиент шлёт письмо с файлом → на киоске «Я отправил письмо» → подтверждение адреса → печать. Предлагается последнее письмо; «Нет» удаляет только его и ищет дальше.

После печати/отправки локальные копии удаляются.

## MAX

В админке:

1. Токен бота и **ID админа** (`user_id`)
2. Галочка **Активировать MAX**

Без галочки, токена или ID бот молчит.

**Пуши админу:** запуск, выключение (Ctrl+C / закрытие), ошибки, бумага ниже порога, отчёт каждый день в 22:00 (выручка, ч/б и цвет, сканы, копии, листы).

**Печать:** отправить файл боту → на киоске подтвердить.

**Скан:** на экране код → написать его боту → PDF придёт в MAX.

API: `https://platform-api2.max.ru`. VPN обычно не нужен (в отличие от Telegram).

## Оплата и бумага

Оплата — заглушка терминала (~5 с). QR пока не подключён. Печать и копирование без оплаты нельзя.

Счётчик листов атомарный: списание до печати/копии, возврат при ошибке. Кнопка «Бумага загружена» в админке сбрасывает остаток на 500.

## Структура

```
main.go                 запуск, graceful shutdown
internal/kiosk/         публичный UI и API киоска
internal/admin/         админка
internal/printjob/      подготовка и печать
internal/scanjob/       сканы
internal/copyjob/       копии
internal/mailinbox/     IMAP
internal/mailout/       SMTP
internal/maxsvc/        бот MAX, пуши, сессии
internal/stats/         дневная статистика
internal/storage/       SQLite, настройки, бумага
internal/usb/           флешки
internal/libreoffice/   поиск/установка soffice
```

Данные: `data/` (БД, задания), `logs/`. После доставки скана PDF с диска удаляется.
