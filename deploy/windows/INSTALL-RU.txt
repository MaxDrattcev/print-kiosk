PRINTUS / PRINT KIOSK
УСТАНОВКА И НАСТРОЙКА НА WINDOWS 11 (64 БИТ)

Читайте разделы по порядку. Все действия выполняются на компьютере киоска.
В примерах приложение находится в C:\PrintKiosk. Если выбрали другую папку,
используйте её вместо C:\PrintKiosk во всех шагах.

1. ПОДГОТОВЬТЕ КОМПЬЮТЕР И ПАПКУ ПРИЛОЖЕНИЯ

1) Войдите в Windows под учётной записью, под которой будет работать киоск.
2) Скачайте архив print-kiosk-windows-amd64.zip.
3) Нажмите на архив правой кнопкой мыши и выберите «Извлечь всё».
4) Перенесите распакованные файлы в постоянную папку C:\PrintKiosk.
   Нужны права на запись в эту папку: здесь создаются база, логи и файлы сканов.
5) Убедитесь, что прямо в выбранной папке находятся:
   print-kiosk.exe
   config.example.yaml
   start.bat
   run-kiosk.vbs
   install-autostart.bat
   uninstall-autostart.bat
   INSTALL-RU.txt

Не запускайте start или install-autostart прямо из архива и не выбирайте
«Запустить», если Windows предлагает «Распаковать» или «Запустить» архивный
файл. Сначала обязательно распакуйте весь архив. Ярлык автозапуска должен
ссылаться на постоянную папку, а не на временную папку распаковщика.

Приложение не требует установки Go, Node.js, Python или Microsoft Office.
Сторонние программы из следующего раздела устанавливаются отдельно.

2. УСТАНОВИТЕ ДРАЙВЕРЫ И НЕОБХОДИМЫЕ ПРОГРАММЫ

2.1. Драйвер принтера и сканера — необходим

Установите полный пакет драйверов производителя для своей модели МФУ.
Для Pantum M6700DW выберите драйверы именно этой модели и вашей Windows.
Один драйвер печати не гарантирует, что будет работать сканер.

Подключите МФУ, включите его и загрузите бумагу. Для первой проверки
используйте USB-подключение, если именно так будет работать ваш киоск.
Откройте «Параметры → Bluetooth и устройства → Принтеры и сканеры»:
- убедитесь, что нужный принтер есть в списке;
- запомните точное имя его очереди;
- откройте свойства принтера и напечатайте тестовую страницу Windows;
- отдельно проверьте сканирование в программе производителя или Windows.

Если Windows сама не печатает или не сканирует, сначала исправьте драйверы,
подключение или состояние устройства. Приложение использует эти драйверы.

2.2. LibreOffice — нужен для Word, Excel и формирования отчётов

Официальная загрузка: https://www.libreoffice.org/download/
Выберите установщик Windows x86-64 и выполните обычную установку.
После установки один раз откройте LibreOffice и закройте его.
Обычно программа находится здесь:
C:\Program Files\LibreOffice\program\soffice.exe

Киоск умеет искать LibreOffice и при отсутствии пытается установить его
на Windows через winget или скачивание MSI. Для этого нужны интернет
и, возможно, подтверждение прав администратора. Удобнее установить его
заранее, чтобы первый запуск не задерживался на загрузке и установке.

2.3. SumatraPDF — установите для надёжной печати PDF без окон

Официальная загрузка:
https://www.sumatrapdfreader.org/download-free-pdf-viewer

Выберите 64-bit. Можно установить обычную версию или скачать Portable ZIP.
Если выбрали Portable, распакуйте его и положите исполняемый файл рядом
с print-kiosk.exe. Для простоты назовите его SumatraPDF.exe.
Не кладите рядом файл установщика вместо самой portable-программы.

Ожидаемый путь для этого варианта:
C:\PrintKiosk\SumatraPDF.exe

Киоск также ищет установленный SumatraPDF в стандартных папках Windows.
Без SumatraPDF приложение может попытаться печатать через ассоциацию PDF
в Windows, но такой способ менее надёжен и может открывать сторонние окна.
Перед эксплуатацией проверьте, что SumatraPDF найден в обзоре кабинета.

2.4. Сканирование: WIA и дополнительная программа NAPS2

Встроенный способ сканирования использует WIA — компонент Windows.
Отдельно устанавливать WIA не нужно, но драйвер МФУ должен поддерживать его.

Дополнительно можно установить NAPS2 для работы сканера:
https://www.naps2.com/download
Выберите установщик Windows x64. Киоск ищет консольную программу по путям:
C:\Program Files\NAPS2\NAPS2.Console.exe
C:\Program Files (x86)\NAPS2\NAPS2.Console.exe
или через PATH.

Откройте NAPS2 и проверьте, что документ сканируется с вашего устройства.
Если NAPS2 найден, киоск сначала пробует его; при ошибке пробует WIA.
NAPS2 не заменяет драйвер производителя. Если установленная версия
не содержит консольную программу по указанному пути, она не будет найдена
автоматически. Сохраните всю папку программы, а не только один EXE.

Текущие настройки сканирования киоска: цвет, 200 DPI. Превью на экране
может подготавливаться отдельно от самого процесса сканирования.

2.5. Браузер

Для интерфейса нужен Microsoft Edge или Google Chrome. Обычно Edge уже
установлен в Windows 11. Приложение открывает отдельное полноэкранное
окно без адресной строки. Не удаляйте браузер после настройки киоска.

3. СОЗДАЙТЕ И НАСТРОЙТЕ CONFIG.YAML

1) В Проводнике включите показ расширений имён файлов:
   «Вид → Показать → Расширения имён файлов».
2) Скопируйте config.example.yaml в той же папке.
3) Назовите копию config.yaml. Проверьте, что это не config.yaml.txt.
4) Откройте config.yaml в Блокноте.

Если config.yaml отсутствует, start.bat создаёт его из примера. Если файл
уже существует, start.bat не заменяет его новым примером. Приложение
при запуске через start.bat читает config.yaml рядом со start.bat.
Правка config.example.yaml не меняет настройки уже созданного config.yaml.

Измените логин и пароль кабинета:
admin:
  username: 'admin'
  password: 'ВАШ_НОВЫЙ_ПАРОЛЬ'

Начальные данные в примере: admin / 123456. До эксплуатации замените пароль.

Укажите принтер и SumatraPDF, например:
printer:
  name: 'ТОЧНОЕ ИМЯ ОЧЕРЕДИ ИЗ WINDOWS'
  sumatra: 'C:\PrintKiosk\SumatraPDF.exe'
  dry_run: false

Если name оставить пустым, используется принтер Windows по умолчанию.
Точное имя предпочтительнее, когда на компьютере несколько очередей.
Если sumatra оставить пустым, программа ищется автоматически.

При необходимости укажите LibreOffice:
paths:
  libreoffice: 'C:\Program Files\LibreOffice\program\soffice.exe'
  print_jobs: 'data/print-jobs'

Эти блоки уже есть в файле — изменяйте существующие строки, не добавляйте
вторые блоки admin, printer или paths. Используйте пробелы для отступов,
не табуляцию. Для путей Windows удобны одинарные кавычки, как в примерах.
Если сам пароль содержит одинарную кавычку, удвойте её внутри такой строки.
Сохраните файл. Изменения YAML вступают в силу после перезапуска приложения.

Порт по умолчанию — 8080. Если измените server.addr, используйте новый
порт во всех адресах этой инструкции. Параметры почты, MAX и Vendista
задаются в кабинете, а не в YAML.

4. ПЕРВЫЙ ЗАПУСК И НАСТРОЙКИ В КАБИНЕТЕ

1) Дважды нажмите start.bat в распакованной папке.
2) Дождитесь запуска сервера и полноэкранного браузера.
   Терминал с журналом запуска должен оставаться открытым.
3) Если браузер не открылся, попробуйте вручную:
   http://127.0.0.1:8080/
4) Откройте кабинет:
   http://127.0.0.1:8080/admin/
5) Войдите с логином и паролем из config.yaml.
6) Проверьте обзор: принтер, сканер, LibreOffice и SumatraPDF.
7) Укажите цены, количество бумаги, доступные услуги и время бездействия.

Тестовый режим оборудования и тестовая оплата — РАЗНЫЕ переключатели.
Для проверки интерфейса оставьте оба включёнными.
Для проверки настоящей печати и сканирования отключите тестовый режим
оборудования в кабинете, но пока оставьте тестовую оплату включённой.
Также в YAML должен быть printer.dry_run: false. Если там true,
выключение тестового оборудования только в кабинете не включит принтер.

Проверьте по одному сценарию:
- печать PDF с флешки;
- печать Word/Excel, если планируете принимать такие файлы;
- две копии одной страницы с двухсторонней печатью;
- сканирование и получение файла;
- копирование.

5. НАСТРОЙТЕ ПОЛУЧЕНИЕ ФАЙЛОВ И ОПЛАТУ

Email: в кабинете укажите адрес, логин и пароль приложения почтового
сервиса. Обычный пароль аккаунта может не подходить. Выполните проверку
и отправьте/получите пробный документ. Нужен интернет.

MAX: укажите токен бота, выполните «Проверить MAX». При успешной проверке
приложение определяет ссылку на бота. Проверьте QR-код и передачу PDF.
Для уведомлений администратору выполните привязку или укажите его ID.
Нужен интернет.

Vendista: в разделе «Оплата» укажите ID терминала и API-токен клиента.
Терминал должен быть зарегистрирован в кабинете Vendista, переведён
в Retail, иметь активные SIM-карту и эквайринг. Компьютеру киоска тоже
нужен интернет. Выполните «Проверить Vendista» — это не списывает деньги.
Обзор показывает время последней связи, а не гарантированную доступность
терминала в текущую секунду.

Пока Vendista не настроена, оставьте тестовую оплату включённой.
После настройки выключите её и проверьте небольшой реальный платёж,
отказ и возврат. До этой проверки не запускайте платный киоск для клиентов.
Фискализация кассовых чеков не реализована в приложении; её подключение
нужно отдельно согласовать с вашим поставщиком платёжного решения.

При ошибке отправки скана можно выбрать другой способ либо отмену
с возвратом. Возврат проверяется по API; срок зачисления зависит от банка.
Неопределённые платежи и возвраты проверяйте в разделе оплаты кабинета
и в Vendista. Не проводите вручную параллельную оплату на том же терминале
во время активной оплаты пользователя киоска.

6. ВКЛЮЧИТЕ АВТОЗАПУСК

Автозапуск срабатывает ПОСЛЕ ВХОДА в учётную запись Windows.
Сам по себе он не выполняет вход пользователя после включения компьютера.
Если Windows показывает экран входа, сначала нужно войти в нужную запись.

1) Убедитесь, что приложение находится в постоянной папке C:\PrintKiosk
   и вручную успешно запускается через start.bat.
2) Полностью остановите предыдущий запуск, чтобы не запускать две копии.
3) Под той же учётной записью Windows запустите install-autostart.bat.
   Обычно запуск от имени другого администратора не нужен: ярлык создаётся
   для текущего пользователя, а не для всех пользователей компьютера.
4) Скрипт создаст ярлык и запустит киоск. Подождите открытия интерфейса.
   Если показано сообщение об ошибке, не закрывайте его до проверки причины.
5) Нажмите Win + R, введите shell:startup и нажмите Enter.
6) Убедитесь, что в открытой папке есть ярлык Print Kiosk.
7) В свойствах ярлыка проверьте:
   - объект: C:\PrintKiosk\run-kiosk.vbs;
   - рабочая папка: C:\PrintKiosk.
8) Перезагрузите компьютер, войдите в эту же запись Windows и убедитесь,
   что полноэкранный киоск открылся без ручного запуска.

Ярлык создаётся в папке автозагрузки, НЕ на рабочем столе.
После настройки не переименовывайте и не переносите папку приложения.
Если перенесли — удалите старый автозапуск и настройте его заново.

Для отключения запустите uninstall-autostart.bat под той же записью.
Это удаляет ярлык автозагрузки, но не закрывает уже работающее приложение.
Если компьютер запрещает выполнение VBS/PowerShell корпоративной политикой,
попросите администратора разрешить штатный способ запуска либо настроить
другой разрешённый механизм. Не обходите ограничения случайными скриптами.

7. КАК ПРАВИЛЬНО ОСТАНОВИТЬ И ПЕРЕЗАПУСТИТЬ

Alt + F4 закрывает окно браузера, но сервер приложения может продолжать
работать. Поэтому закрыть только браузер недостаточно для применения YAML
или замены EXE.

Если запускали start.bat: перейдите в его консоль и нажмите Ctrl + C.
Если запускали скрыто через автозапуск: откройте Диспетчер задач
(Ctrl + Shift + Esc), найдите print-kiosk.exe и завершите этот процесс.
Останавливайте приложение после завершения печати, сканирования и оплаты.

Затем запустите start.bat или run-kiosk.vbs. Не запускайте оба одновременно.
run-kiosk.vbs запускает сервер без видимого окна консоли.

8. ОБНОВЛЕНИЕ И РЕЗЕРВНАЯ КОПИЯ

1) Дождитесь окончания текущих операций и остановите приложение.
2) Сохраните резервную копию папки C:\PrintKiosk, особенно:
   config.yaml — логин/пароль и системные параметры;
   data — база настроек, статистики и платёжных операций;
   logs — журнал для диагностики.
3) Распакуйте новую сборку отдельно и замените программные файлы.
4) Не заменяйте свой config.yaml файлом config.example.yaml и не удаляйте data.
5) Если состав настроек изменился, перенесите нужные изменения из примера
   вручную, сохранив свой пароль и пути.
6) Запустите приложение, проверьте обзор и пробную операцию.

Если постоянная папка не изменилась, ярлык автозапуска обычно менять не нужно.

9. ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

Киоск не открывается:
- Запустите start.bat и прочитайте сообщение в консоли.
- Проверьте наличие EXE, config.yaml и правильность отступов YAML.
- Если порт 8080 занят, проверьте, не работает ли старая копия print-kiosk.exe.
- Если сервер доступен вручную по адресу, проверьте наличие Edge/Chrome
  и параметр server.open_browser (по умолчанию включён на Windows).

Пароль не подходит:
- Меняйте admin.password именно в config.yaml запускаемой папки.
- Полностью остановите print-kiosk.exe и запустите заново.
- Проверьте, что не запускаете старую сборку из другой папки.

Автозапуск не работает:
- Проверьте ярлык через Win + R → shell:startup под нужной записью.
- Проверьте, что Windows не отключила этот элемент в списке автозагрузки.
- Проверьте пути ярлыка: в них не должно быть временной папки архива.
- Убедитесь, что вошли в Windows. Затем попробуйте start.bat вручную.
- Отсутствие ярлыка на рабочем столе не является ошибкой.

Принтер или сканер не найден:
- Проверьте питание, USB, бумагу и ошибки на дисплее МФУ.
- Проверьте тестовую печать и сканирование вне киоска.
- Проверьте точное имя очереди и полный пакет драйверов.
- Если не работает WIA, откройте «Службы» и проверьте службу
  «Служба загрузки изображений Windows (WIA)».

Документ Word/Excel не открывается: проверьте LibreOffice и путь soffice.exe.
При печати появляются сторонние окна: проверьте, что найден SumatraPDF;
отдельные уведомления драйвера МФУ настраиваются средствами производителя.
Полноэкранный браузер не является блокировкой всех системных жестов Windows.

Логи по умолчанию находятся здесь:
C:\PrintKiosk\logs\kiosk.log
Чтобы открыть папку: Win + R → C:\PrintKiosk\logs → Enter.
Если logging.path изменён, используйте путь из config.yaml.

Для обращения в поддержку сохраните kiosk.log, точное время ошибки,
модель МФУ и описание действий. Не отправляйте пароли и API-токены.

ОПЛАТА СБП ПО QR-КОДУ НА ЭКРАНЕ КИОСКА

1. Зарегистрируйте магазин в PayMaster и подключите приём СБП.
2. Получите ID магазина (merchantId) и API-токен с правами на платежи
   и возвраты. Это отдельные реквизиты, не токен и ID Vendista.
3. В разделе «Оплата» включите «Включить СБП», введите реквизиты,
   сохраните настройки и нажмите «Проверить PayMaster / СБП».
   Проверка доступа не создаёт платёж и не подтверждает подключение СБП
   по договору: эту услугу нужно активировать в PayMaster.
4. С включённым тестовым режимом выберите оплату по QR. QR помечен
   как тестовый и не предназначен для банка; нажмите «Подтвердить
   тестовую оплату», чтобы проверить весь сценарий без списания денег.
5. Выключите тестовый режим и проверьте реальную небольшую оплату,
   отказ, отмену и возврат. Рабочий QR действует 2 минуты. Приложение
   проверяет статус на сервере PayMaster и продолжает только после
   подтверждения проведённого платежа с совпадающей суммой и заказом.
6. При потере связи не оплачивайте повторно: приложение сохраняет
   незавершённый платёж и сверяет его автоматически. Позднее списание
   по прерванной операции возвращается. Возвраты выполняются через
   PayMaster; проверить их можно также в кабинете PayMaster.

Киоску нужен интернет для PayMaster; SIM-карта Vendista для СБП
на большом экране не используется. Публичный адрес для уведомлений
не нужен: приложение опрашивает API. Фискализацию согласуйте отдельно.
Документация: https://paymaster.ru/docs/ru/api/
